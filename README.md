# OPC Operating Modes — v0.5

四个可独立使用的 skill，依据《OPC Operating Modes》理论框架初稿 v0.1，将三种执行模式与一种战略模式连接成可记录、可复盘的工作流程。

当前 skill 包版本为 v0.5，基于理论框架初稿 v0.1。skill 版本与理论版本分别管理；版本号不表示实际经营验证轮次。

## 四个入口

| Skill | 主导目标 | 主要增强 |
|---|---|---|
| [Marketing](marketing-operation-mode/SKILL.md) | 市场认知与合格机会 | 洞察、直接成稿、渠道与线索承接分支；可信度贯穿全过程 |
| [Sales](sales-operation-mode/SKILL.md) | 适配客户的自主购买决定 | 无具体客户也可准备销售；四类适配判断；实际承诺与验收交接 |
| [Delivery](delivery-operation-mode/SKILL.md) | 在合理投入内兑现价值 | 公开内容也可能是交付；成果证据、验收、工时成本和变更记录 |
| [Strategy](strategy-operation-mode/SKILL.md) | 检验假设并支持经营决策 | 修正模式身份；区分建议与决定；有限实验、模式失衡与反馈闭环 |

每个 skill 保留自己的 `SKILL.md`、`VERSION` 和按需读取的 `references/`，无需依赖其他三个目录。根目录模板和理论副本是辅助材料，不是独立使用 skill 的前置条件。四个入口均保留最小的模式进入、上下文、切换、记录与退出规则，以保证拆开使用时规则仍完整。

## v0.5 的主要改进

| 修改 | 实现 |
|---|---|
| 修正 Strategy 身份错误 | Strategy 明确为三个 Execution Modes 之外的战略复盘与学习模式 |
| 补齐参考文件入口 | 每个参考文件均有可达链接；入口说明何时读取，避免无差别加载 |
| 统一进入与退出规则 | 当前目标、成功标准、需要克制的习惯、实际产物、结果与待办；支持同一任务多模式 |
| 共用经营上下文与反馈记录 | 统一字段与状态；有指定位置且已授权时保存，否则返回可交接文本；不假定跨会话记忆 |
| 补齐产物、指标和案例 | 各模式按任务交付具体产物；指标定义分母、窗口和未知项；案例明确为示例 |

## 经营记录的最小使用方式

1. 在用户指定的经营资料位置，从[经营上下文模板](templates/business-context.md)建立一份实际记录；不把包内空模板当作生效政策。
2. 根据任务使用相关 skill，只读取当前需要的参考文件。
3. 必要时从[工作与交接记录模板](templates/operating-record.md)选取字段，记录真实证据、结果、决策状态和下一步。
4. Strategy 复盘时整合反馈；用户已作出或已委托的决定才更新生效上下文。建议与待决定项单独保留。

没有指定记录位置时，先在回答中提供可交接记录，不阻塞正常工作，也不声称已保存。输出长度服从任务：要文案就先给文案，要交付物就给交付物，简单问题不强制展开全套报告。创建记录或实验计划本身不等于执行外部操作。
